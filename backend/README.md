# Pokemon Effectiveness App

A small desktop app to have open while playing Pokemon. \
Enter the type(s) of the opponent's Pokemon and see how effective each attack type will be.

## Usage

The gradle task 'createExe' will create an .exe.

For development the task 'runJar' will run the app for you.
